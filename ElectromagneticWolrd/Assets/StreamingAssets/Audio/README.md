# 소리 파일 교체 안내

효과음은 이 폴더에서 **앱을 실행할 때마다 읽어 옵니다.**
파일만 바꾸고 앱을 다시 켜면 반영됩니다(다시 빌드하지 않아도 됩니다).

- 개발 PC: `Assets/StreamingAssets/Audio/`
- 설치한 PC: `<앱 폴더>/ElectromagneticWorld_Data/StreamingAssets/Audio/`

이 전시물은 **서브 콘텐츠**라서 배경음악(BGM) 없이 관람객 동작에 짧은 효과음만 냅니다.
같은 공간의 메인 콘텐츠 소리를 가리지 않도록 크기도 작게 잡아 두었습니다.

## 언제 어떤 소리가 나나요

| 키 | 파일 | 나는 때 |
|---|---|---|
| `pickup` | `sfx_pickup.wav` | 레일에서 카드를 꺼낼 때 (위로 차오르는 전파 스윕) |
| `close` | `sfx_close.wav` | 꺼낸 카드의 X 버튼으로 레일에 돌려보낼 때 (내려가는 스윕) |
| `flip` | `sfx_flip.wav` | 카드 뒤집기 버튼을 누를 때 (뒤집기 기능을 켠 경우만) |
| `select` | `sfx_select.wav` | 정보검색 칸에서 메뉴를 고를 때 (두 음 차임) |
| `button` | `sfx_button.wav` | 정보검색 칸 [이전으로], 설정창 볼륨 조절바 미리 듣기 |

시간이 지나 카드가 저절로 레일로 돌아갈 때와 무입력 대기 복귀 때는 소리를 내지 않습니다.

## sound.json

키마다 파일 이름과 개별 크기(0~1)를 적습니다.

```json
{ "key": "pickup", "file": "sfx_pickup.wav", "volume": 0.6 }
```

- 파일 형식: `.wav`, `.ogg`, `.mp3`
- 파일을 바꿀 때는 같은 이름으로 덮어쓰거나, `file`을 새 파일 이름으로 고칩니다. **`key`는 바꾸지 않습니다**(코드가 키로 부릅니다).
- 파일이 없거나 깨져도 앱은 멈추지 않고 그 소리만 나지 않습니다(로그에 경고 한 번).
- 나중에 BGM이 필요하면 키를 추가하고 코드에서 `PlayBgm("키")`를 부르면 됩니다.

## 전체 크기 조절

ESC 설정창의 **소리** 칸에서 전체 볼륨·효과음 볼륨 조절바와 효과음 음소거를 바꿀 수 있습니다.
바꾼 값은 바로 들리고 `<persistentDataPath>/soundSetting.json`에 저장됩니다(빌드를 덮어써도 유지).

## 지금 들어 있는 소리 (임시)

지금 파일은 실제 소리를 받기 전까지 쓰는 **임시 효과음**입니다.
외부 음원을 쓰지 않고 `Tools/gen_sfx.py`로 **직접 합성**했습니다(저작권 문제 없음).
콘셉트는 "전자기파": 맑은 사인파와 주파수가 오르내리는 파동, 살짝 반짝이는 배음입니다.
다시 만들려면 프로젝트 폴더에서 `python Tools/gen_sfx.py`를 실행합니다(numpy 필요).
